# EAiCoding 0.1.9

修复 DeepSeek 思考模式返回 `The content[].thinking in the thinking mode must be passed back to the API` 后任务中止的问题。

- 应用自动查询模块库、解析上传模块和查询已选方案时，将实际工具结果作为应用证据传入，不再构造没有模型思考内容的 assistant/tool_use 对话；界面执行记录、模块检索及依赖传递保留。
- 参考 Harness `687f282` 的 `llm-deepseek/serialize.ts`、`replay.ts` 和思考工具续调测试，推理文本独立于原生重放保存。重放缺失或损坏仍回传已有推理；切换模型只丢弃不可复用的签名，不丢弃推理文本，也不补造推理或签名。
- 修复最终回复的推理文本被界面清空、旧回复压缩丢失推理状态的问题。已有会话可从保存的最终回答轨迹恢复，无需清空记录；旧记录中从未保存的内容无法还原。
- 基线构建替换工具时，DeepSeek 继续保留原始思考签名并发送当前调用；其他协议继续清理失配的原生调用，避免执行旧工具。自检修正轨迹也保存原生重放。

升级保留账号、会话、模型配置和模块库。名称、图标、主题、主窗口默认 1120×720 和托盘关闭行为保持现有配置。

验证使用本地 IPC/SSE fixture，不读取真实账号、不调用付费模型。新增回归先在旧实现复现失败，再验证签名分片、两轮真实适配器工具续调、模块依赖传递、模拟编译交付、JSON 持久化及旧会话恢复。离线通过不代表已验证真实服务的延迟或生成质量。

已通过前端生产构建、最终 TypeScript 复查、模型协议与 Agent runtime 回归、方案选择及检索回归、Edge 全流程界面回归。界面测试同时检查推理持久化、完成后不重复显示和流式滚动；倒退、收缩和底部间隙指标均为 0。

`EAiCoding_0.1.9_x64-setup.exe` 为安装包，`EAiCoding_0.1.9_x64-portable.zip` 为便携包；用 `SHA256SUMS.txt` 校验附件。
