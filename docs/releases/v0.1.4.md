# EAiCoding v0.1.4 — 账号中心与安装流畅度

- 安装解压改为 Harness 的独立 7-Zip 进程并读取真实工作进度，避免大文件期间按指令计数的进度停滞；压缩包不重复压缩。
- 安装进度页复用画布与品牌图，只刷新动态区域；准备 WebView2 时显示对应状态，成功后才进入 100% 和完成页。
- 左下角显示头像和账号名，点击向上展开设置和退出登录；菜单位置、尺寸和交互参考 Harness 源码。
- 设置默认打开个人中心，展示账号资料、充值余额与赠金余额，并提供官方账号、用量和充值入口。模型参数保留在模型页。
- 余额采用 Harness 十进制格式规则；读取失败可重试或前往开放平台，不伪装为零余额。
- 退出前弹窗确认，运行中的任务会提示中断；取消继续执行。退出或换账号后不会被迟到请求恢复旧资料。
- 保留 EAiCoding 自有名称、图标和 Claude 暖色主题。

## 附件

- `EAiCoding_0.1.4_x64-setup.exe`：Windows x64 安装版。
- `EAiCoding_0.1.4_x64-portable.zip`：完整解压后运行 `EAiCoding.exe`，保留同目录工具文件。
- `e.zip`：独立易语言环境包。
- `SHA256SUMS.txt`：附件校验值。

升级前从系统托盘退出旧程序并保存工程；会话、模块库及有效授权继续保留。本版沿用 0.1.3 的覆盖安装目录修复。

验证使用本地模拟账号和 HTTP 服务，覆盖资料/余额、失效、失败降级、退出及迟到结果隔离；未用个人凭据请求真实官方资料、余额或模型。插件系统与定时自动化尚未包含，完整范围见开发文档。

安装流程已使用无害 fixture 验证：128 MiB 实际解压及哈希一致，工作线程暂停期间窗口移动/消息响应，缺失压缩包和解压工具均返回失败。实际安装耗时仍受磁盘、杀毒扫描及 WebView2 下载影响；未自动安装或关闭用户正在运行的程序。
