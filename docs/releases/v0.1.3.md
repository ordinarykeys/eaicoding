# EAiCoding v0.1.3 — 模块详情、工作区与执行修复

- 模块整理和向量计算移到后台线程，按复制、原生解析、整理、模型加载和索引数量显示真实进度。
- 点击导入模块可查看命令签名、参数、类与程序集、其他声明及完整解析文本。内置精易知识库也可浏览分类条目。
- 修正 6779 个内置文档条目与导入模块命令数的统计口径；搜索只推荐公开接口，自动携带依赖路径。
- 去掉额外 Reviewer 请求和全局两次重写限制，任务按工具结果继续执行；有新修改仍须构建验证。
- 左侧工作区分组与任务搜索，顶部会话复制/导出，右侧文件、代码、PowerShell 终端和内嵌浏览器。
- 修复本地打开的 ACL 授权，增加原生剪贴板与复制回退。
- 点击关闭隐藏到右下角系统托盘；点击托盘或再次启动恢复，右键“退出 EAiCoding”才退出程序。
- 修复打开易语言环境页卡死：改为手动后台扫描，阻止重复扫描与旧结果覆盖；递归跳过目录链接，统计不完整时显示提示。移除通用设置多余的分割线。

## 附件

- `EAiCoding_0.1.3_x64-setup.exe`：Windows x64 安装版。
- `EAiCoding_0.1.3_x64-portable.zip`：完整解压后运行 `EAiCoding.exe`，保留同目录 `eagent-tools`。
- `e.zip`：独立易语言环境包。
- `SHA256SUMS.txt`：附件校验值。

升级前退出旧程序，保存项目源码。会话和已导入模块保存在原应用数据目录；旧模块索引无需批量重建。详情新增的声明列表可从已有解析文本按需整理。

仍使用 DeepSeek API Key。Harness 的官方账号授权、插件系统及定时自动化不在本版中。详情显示解析器实际导出的内容，未导出的二进制资源不计入统计。实际模型生成质量、业务接口及任意第三方工程依赖仍需具体任务验证。
