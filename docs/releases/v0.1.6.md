# EAiCoding 0.1.6

对照 DeepSeek Harness 0.2.1-rc.2（687f282）更新模型配置、窗口结构和账号交互。

- 标题栏与侧栏一体，主内容左上角圆角；设置遮罩不再盖住 40px 标题栏，保留自己的名称、图标和 Claude 暖色主题。
- 主窗口默认缩小为 1120×720，仍支持调整大小和最大化。
- 支持 42 个提供商目录及自定义中转、模型发现、分组搜索选择；移除自行加出的全局高级参数。推理强度随具体模型能力，官方模型默认高。
- 官方 DeepSeek 改用 Harness Messages 协议，第三方复用同版 pi-ai SDK；模型选择会影响实际端点、协议与工具循环。
- 新增官方网页搜索/读取开关和账号赠金堆叠通知；修复提供商保存后锁住操作等问题。

升级保留账号、会话和模块库；新 API 密钥由本机 Rust 加密保存。官方账号和第三方凭据相互独立。第三方 API 可独立使用，无需先登录 DeepSeek。

补齐 Harness 已提供的全部第三方认证方式：Claude、Copilot、Kimi、Meta、Codex、OpenRouter、Radius、xAI 授权，以及 AWS Profile/凭据链/SigV4、Google ADC/服务账号、Azure、Cloudflare、Anthropic WIF。支持设备码、手动回填、取消、过期刷新和断开连接。安装包自带 Node 运行时与依赖许可，无需另装 Node。

通过隔离环境中的真实 SDK + 模拟授权服务、本地 AWS 签名请求和 Edge 界面回归验证；未使用真实账号或付费接口验收。SDK 额外提供的新版 OpenAI ChatGPT 登录未展示，与 Harness 的 `UNSERVED_OAUTH` 规则一致；可使用其 Codex 入口。

附件：`EAiCoding_0.1.6_x64-setup.exe` 为安装包，`EAiCoding_0.1.6_x64-portable.zip` 为便携包；`e.zip` 为独立工具链，`SHA256SUMS.txt` 用于校验附件。使用现有安装器升级，无须退出到命令行运行构建工具。
