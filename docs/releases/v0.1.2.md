# EAiCoding v0.1.2 — 易语言自动编程与交互优化

## 更新内容

- 仅接入 DeepSeek-V4.1-Flash / DeepSeek-V4-Pro，统一实际请求模型、输入区选择和密钥配置。
- 完善 AI 自动读写、原生窗口工程生成、回编及编译验证；最后一次源码修改必须验证后交付。
- 取消桌面任务固定总步数，修复任务未完成就按步骤上限结束的问题；仍可随时停止。
- 默认最大输出 Token 提高到 256000，加入输出截断后的有限自动拆分重试，不执行残缺工具参数、不重做成功操作。
- 参考 DeepSeek Harness 优化设置弹窗、模型菜单、工具执行记录和右侧文件预览，保留 Claude 暖色主题。
- 修复流式回复上下抖动，增加增量代码高亮和用户上翻阅读保持。
- 模块库支持 `.ec` 导入、本地索引、搜索和每页 20 行，改善大量模块的列表性能。
- 补充使用文档、架构说明，以及 Agent、高亮、界面和原生窗口回归。

## 下载与使用

- `EAiCoding_0.1.2_x64-setup.exe`：Windows x64 安装版，按向导安装。
- `EAiCoding_0.1.2_x64-portable.zip`：Windows x64 免安装版，完整解压后运行目录中的 `EAiCoding.exe`；保留同目录 `eagent-tools`，不要只复制主程序。
- `e.zip`：单独提供的易语言运行环境包，供源码开发使用，放到 `src-tauri/resources/eagent-tools/eroot/e.zip`。安装版及便携版已携带该包，无需额外下载一份。
- `SHA256SUMS.txt`：安装包、便携归档、环境包及发布说明的 SHA256 校验值。

需要 Windows 10/11 x64 和 Microsoft WebView2 Runtime。首次运行进入「设置 → 模型」填写自己的 DeepSeek API Key；既有安装的应用标识保持不变，设置和会话按本地存储迁移。便携版可执行文件免安装，应用数据仍保存在本机用户目录，并非所有设置都跟随目录移动。

## 验证与边界

前端生产构建、Agent/高亮/选择/语法/检索回归、Edge 界面回归，以及 Rust 单元和原生窗口测试通过。发布产物另核对版本、工具链文件和归档完整性。尚未使用真实 DeepSeek API 验证本轮改动；复杂工程依赖与模型实际生成质量仍取决于具体环境。

默认官方接口的旧版 8192 输出额度会迁移到新默认，其他自定义额度和代理配置保留。兼容代理需自行确认模型与输出额度支持。
