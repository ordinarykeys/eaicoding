# EAiCoding 0.1.10

修复新任务继承其他任务的“思考中”、发送被错误排队，以及长思考内容撑出横向滚动条的问题。

- 运行状态、流式缓存、取消句柄与待发送消息按会话隔离。A 任务运行时，新建 B 可以立即发送；停止 B 不会停止 A，A 完成也不会清除 B 的运行状态。后台任务成功完成后会自动继续自己的队列，失败或停止则保留队列供手动操作。
- 输入草稿和附件按任务保存，切换任务互不覆盖；模型配置尚在读取时新建任务不会丢弃正在准备的空会话。
- 对照 Harness `687f282` 的 `ui-conversation/queue/QueueDock.tsx` 与 CSS：单条队列直接预览，多条默认折叠为数量栏；队列贴合输入框，提供图标形式的原位编辑、删除与向上发送。运行中发送所选消息作为插话，停止后可手动发送指定消息；只在接受成功后移除。空输入框 Ctrl/Cmd+Enter 插话发送全部排队消息。
- 对照 Harness `ui-chat/chat/ReasoningRow.module.css` 的布局包含和可收缩摘要，同时修正消息滚动容器的固有宽度；长连续推理文本在折叠、展开及右侧工作区显示时不撑大消息列，代码区域保留自身滚动能力。

队列和未发送草稿保留在本次应用运行内存中，重启不会恢复。插话在模型/工具边界处理，当前工具执行会先完成。

验证使用本地模拟 IPC/SSE 和 Edge，不使用真实账号或商业模型。界面回归覆盖真实生产 CSS 下的长推理宽度、窄窗口和工作区分栏，队列编辑/删除/指定插话，以及两个独立请求的输出、停止、两种完成顺序与后台队列。

`EAiCoding_0.1.10_x64-setup.exe` 是安装包，`EAiCoding_0.1.10_x64-portable.zip` 是便携包；可使用 `SHA256SUMS.txt` 核对附件。
