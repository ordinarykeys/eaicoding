# EAiCoding 0.1.8

- 左上角增加“应用 / 编辑”菜单。对照 Harness 的 Windows 源码，使用标题栏按钮和系统原生弹出菜单；编辑操作保留输入焦点和选区，支持撤销、重做、剪切、复制、粘贴、删除和全选。
- 应用菜单提供关于、检查发布版本和退出确认。关闭主窗口继续隐藏到托盘。更新检查读取 EAiCoding 的 GitHub Releases；查看发布版本才打开浏览器，不自动安装。未移植 Harness 专属 dsh 命令管理和托管更新服务。
- 移除界面悬浮 tips、原生 title 提示、输入框快捷键及终端底部说明。保留必要的执行状态、错误、确认和交互式授权指令。
- DeepSeek HTTP 错误显示服务端校验原因并脱敏；对齐 Harness 的空消息过滤、工具调用与结果配对检查，修正旧重放内容覆盖当前工具调用的问题。

升级保留账号、会话、模型配置和模块库。名称、图标和主窗口默认 1120×720 保持 EAiCoding 配置。

已通过前端生产构建、DeepSeek 协议 fixture、Edge 全流程及真实 Windows 菜单回归；编辑操作验证了实际剪贴板和撤销历史。流式滚动回归的倒退、收缩和底部间隙指标均为 0。

`EAiCoding_0.1.8_x64-setup.exe` 为安装包，`EAiCoding_0.1.8_x64-portable.zip` 为便携包，附件完整性可通过 `SHA256SUMS.txt` 校验。

HTTP 400 的旧提示未保存服务端原因，因此不能据此断言那次失败的唯一原因；本次使用离线协议 fixture 验证错误详情和历史处理，不调用真实付费模型。
