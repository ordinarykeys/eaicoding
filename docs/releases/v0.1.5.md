# EAiCoding v0.1.5 — Harness 交互与代码工作视图

- 修复设置内的复制、导入等操作提示被遮罩盖住、变暗和模糊的问题。
- 参考 Harness 源码，将通知通过 Portal 挂到页面最外层；保留现有提示样式和设置交互。
- 界面回归覆盖模块签名复制的剪贴板内容、通知实际显示层级、设置保持打开与焦点保留。
- 发送按钮采用 Harness 源码的 34×34 圆形和 16×16 箭头，保留 EAiCoding 主题色。
- 通用设置新增繁忙发送行为：排队发送或插话发送，Ctrl+Enter 使用另一行为。运行中有草稿时显示发送与独立停止按钮；排队支持编辑、取消，本轮成功后继续发送。
- 用量和充值通过应用内全窗口官方网页打开，提供返回、加载与失败重试；返回后刷新余额。更多账号信息仍使用官方网页链接，支付服务主动打开的 HTTPS 新窗口按 Harness 行为交给浏览器。
- 新增代码工作视图开关、对话/轨迹标签、轨迹搜索及记录检查和复制。
- 右侧本轮改动页支持文件选择、增删行、统一/并排和换行；同文件多次编辑比较首次修改前与最后修改后，移除旧的工具区“原始/优化后”切换。
- 差异来自成功文本写入与补丁的原生快照，不向模型重复发送快照全文。为控制会话体积，单次修改的任一侧超过 1 MiB、读取失败或旧记录缺少快照时不展示完整差异；二进制产物仍通过文件入口查看。
