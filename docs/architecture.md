## 模型与配置

仅公开 `deepseek-flash`（DeepSeek-V4.1-Flash）和 `deepseek-v4-pro`（DeepSeek-V4-Pro）。目录及旧模型 ID 迁移统一在 `src/lib/deepseek-models.ts`；输入区选择改变实际请求模型。旧协议适配器文件仍可能存在，但桌面模型工厂不会使用其他厂商。

请求通过 Rust 网络代理访问 `/chat/completions`。API Key 在本机加密保存，编辑框不回填明文；加密或存储失败会恢复原配置。模型连接检测通过 `/models` 筛选支持目录。

默认最大输出为 256000 Token，温度 0.2。设置持久化版本为 v7：只将旧版官方端点的默认 8192 迁为新默认，其他有效自定义值及代理额度保留。显式输出额度约束当前请求，截断恢复不会私自扩大该值。最终答案只进行本地证据和 EPL 结构检查；不再发起独立 Reviewer 请求或重复编译。

## 执行与完成

```text
用户需求
  → 识别独立问候或开发任务
  → 组装上下文、必要的知识证据和原生工具定义
  → DeepSeek 流式推理 / 正文 / 工具参数
  → 整批参数完整性校验
  → 执行工具并保留结果
  → 继续下一轮；有源码修改则要求最新版本构建
  → 完成交付，或报告取消 / 具体失败 / 未完成原因
```

- 独立问候、致谢和能力介绍使用轻量提示词，不带旧工程历史和工具；正常只需一轮。混合开发需求仍走开发流程。
- 开发任务默认自主分析接口和实现方案，自动读写；知识库返回多个入口不会自动转换成用户选择题。只有业务信息缺失或用户明确要求时才使用结构化提问。
- 桌面入口没有固定总轮数或整轮计时上限。调用方可显式传入 `maxSteps`，用于集成和测试。
- 主模型单次请求仍有 180 秒超时；网络失败最多重试两次。连续相同失败且无源码变化、连续空响应或相同本地检查失败且无新工具证据时报告明确原因。成功读取同一文件不会触发重复操作终止；每次修改后构建重试计数重新计算。
- 源码保存、精确替换、恢复快照或工程生成都会影响修改状态。最新修改之后必须再次验证，旧构建不能证明新源码可用。
- `build_ecode_project` 已包含回编和编译；成功后无需重复 `compile_efile`。转换器即使输出 `SUCC`，有解析错误日志也按失败处理。
- 停止信号贯穿模型请求、已接入的工具和 Rust 任务注册；忽略迟到流内容。恢复上次中断会话时保留结果、清除失效的运行标记。

### 输出截断恢复

`finish_reason=length` 生成独立的 `LLMOutputLimitError`。适配器先校验整轮，再发布工具调用，因此截断批次内即使有一个看似完整的调用也不会执行。

执行器丢弃本轮残缺正文、推理和工具参数，在同一模型轮内最多恢复两次。恢复提示逐次要求只完成一个文件片段、子程序或最小补丁，其余工作交给后续工具轮。既有成功工具和结果保持原样，残缺 JSON 不会拼接到下一次请求，恢复指令只作用于当前重试。

输出恢复计数与网络重试计数独立，也不占用新的正常工具轮。仍被截断时明确以未完成错误结束，不把残缺源码或失败候选答案显示为交付。

## 易语言工程与知识库

已有 `.e` 工程优先使用 `start_project_closed_loop` 做导出、项目地图、原始基线、上下文与快照；允许编辑后读取推荐源码，修改 `.e.txt`，再用 `finish_project_closed_loop` 验证。基线、依赖或环境不满足时不能跳过检查声称完成。

新建窗口使用 `generate_gui_project`：`.form.json` 保存几何布局，`.form.e.txt` 保存窗口程序集和事件，再回编 `.e`、编译 `.exe`。目前支持按钮、编辑框、标签、选择框和单选框；不等同于任意控件的可视化设计器。

大文件可按范围读取并返回哈希。精确替换在后端对完整文件执行，要求唯一匹配，并可校验预期哈希；编码和换行尽量保持。`.e/.ec` 必须用解析工具，不按普通文本读取。

用户模块库接收 `.ec`，文件副本保存在应用本地目录；设置只存小体积元数据，API 和向量索引分开保存在 IndexedDB。模块库页懒加载、延迟搜索，每页 20 行。嵌入模型为随项目提供的本地 `bge-small-zh-v1.5`，ONNX 运行时通过 `scripts/prepare-ort.mjs` 从锁定的 npm 依赖准备，禁止回退下载远程模型。

## 展示与滚动

- 正文直接显示流式 Markdown；推理与正文分开，工具过程使用可展开的单行记录。调用数据只有展开时才挂载，完成后收起过程。
- 右侧工作区保留开始、文件、代码、多个终端与浏览器页签；收起时保持状态，关闭页签或切换会话释放对应资源。代码支持独立滚动、复制、保存、系统打开、换行和宽度调整。新增工具结果不抢当前文件。
- 长文件预览分页加载并检查哈希，文件变化停止拼接，读取失败保留现有内容供重试。二进制工程和可执行文件使用独立打开入口。
- `useLayoutEffect` 和直接 `ResizeObserver` 回调在显示前校正底部位置，区分程序滚动、内容收缩和用户上翻。向上阅读暂停跟随，“回到最新”恢复；关闭浏览器滚动锚定和平滑滚动。
- 代码高亮缓存已完成行及语法状态，只重算增长尾部；高亮加载和追加过程中保持同一 `pre/code` 及已有行节点，避免字体几何变化和整块替换引起抖动。

## 与参考项目的关系

DeepSeek Harness 为本地只读对照项目，没有修改其源码或以它作为运行时依赖。对照包括 `ui-conversation/InputBar`、模型选择、`ui-chat/TurnProcessNodeView`、`ui-tool/ToolRow`、`ui-sidebar-documentpreview/TextPreview`、`core/agent-loop` 和 `llm-deepseek`。保留本项目的 Claude 暖色主题、React/Tauri 架构与易语言工具。

Harness 的 DeepSeek 默认输出额度为 256000，使用 Messages 协议；本项目使用 Chat Completions。默认预算、原生工具循环和滚动机制已参考实现，但并未完整移植其 Markdown 分块缓存、所有工具独立滚动和折叠位置保持逻辑。Harness 也会区分 `max-tokens` 与正常完成；本项目额外增加了上述有限截断恢复。

[AutoLinker](https://github.com/aiqinxuancai/AutoLinker) 用于参考分页读取和哈希校验修改；原生窗口生成由本项目实现。

## 已知边界

工具上下文还没有统一的 Token 总预算；过多源码或工具结果仍可能超出模型上下文。本地结构检查不能代替实际编译和业务验证，文件修改后的构建证据必须覆盖最新源码。桌面 Rust 和前端检索路径尚未做统一端到端验收，复杂工程依赖与停止后编译器派生进程树也需继续验证。

当前自动化主要使用模拟模型传输；构建和回归通过不代表真实 DeepSeek 的连接、延迟、工具选型或生成质量已经验证。验证方法见[开发与验证](development.md)。

## 模块导入与工作区原生能力（0.1.3）

模块导入先登记“复制中”，由 Rust 复制 `.ec` 并返回大小，避免用文本读取器读取二进制来统计大小。原生解析结束后，ES Module Worker 整理命令、程序集及其他声明，并分批建立本地语义向量。Worker 复用嵌入模型、串行安排向量任务，解析请求不排在整个向量队列之后。主线程只接收阶段和数量更新，词法索引先于向量索引可用。详情按需读取，原始文本分页，不把整份模块挂载到 DOM。

用户库先于精易库进行自动预查；模块详情包含内部声明，但搜索仅返回公开接口。结果包含依赖路径，运行器记录本轮检索/解析确认的 `.ec`，传给生成与编译工具。同一批次后续调用也能获取新发现的依赖。

`workspace.rs` 提供目录分页、ConPTY PowerShell 终端和 Tauri 子 WebView。目录限制在所选工作区内；终端在关闭页签时结束进程。浏览器仅接受 http(s) 网页，隐藏页签或打开设置时隐藏原生表面，并跟随布局位置。默认插件能力只赋予 `main` WebView；应用自定义命令另在调用入口拒绝子网页，避免仅依赖插件 ACL。主视图显式获得 `opener:allow-open-path`，修复本地打开的 ACL 错误。

`system_tray.rs` 创建 Windows 托盘图标与打开/退出菜单；主窗口的 `CloseRequested` 由 Rust 拦截并隐藏，保留 WebView 和当前任务。托盘左键、打开菜单和单实例回调复用恢复逻辑；明确选择退出时才调用应用退出。

易语言环境页仅在点击“扫描环境”后调用异步命令，文件遍历由 `spawn_blocking` 执行，不占桌面事件线程；全局信号量拒绝重叠扫描。前端用请求序号丢弃目录更改或弹窗关闭后的旧结果。递归文件统计跳过符号链接及 Windows junction，每轮限制 100,000 条目、64 层及 10 秒检查预算；单次系统文件调用自身不承诺超时。遇到跳过项或达到预算时返回 `counts_complete: false` 与警告，数量仅代表已扫描部分。
