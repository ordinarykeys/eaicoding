## 模型与配置

官方账号公开 `deepseek-flash` 与 `deepseek-v4-pro`，由 `deepseek-models.ts` 统一迁移、显示与四档推理能力。账号请求采用 Harness 的 `/anthropic/v1/messages`，默认高强度；保留 Messages thinking 签名、工具块与立即对应的结果。旧 Chat Completions 适配器仅用于兼容历史调用及协议回归。

`model-settings.tsx` 按需加载目录，创建/编辑提供商；元数据存 IndexedDB v9，密钥由 `model_providers.rs` 加密存 `model-providers-v1.json`。网络代理按已保存 profile、origin、路径和协议校验并注入凭据；同一厂商的多协议/区域端点分别登记，不把密钥传给未经保存的端点。未保存的发现端点不能沿用旧端点密钥。

内置 42 个提供商使用 `runtime/model-runtime.mjs` 与随包 Node，复用 Harness 同版 pi-ai 1.1.0 的 provider/auth/stream 实现，覆盖其全部已提供认证方式。Rust `model_runtime.rs` 通过 stdin/stdout 行协议传递本地已登记配置，授权事件只向前端投影通知、提示和模型输出；完整凭据不会经过 webview。OAuth 与结构化云凭据加密存于 `model-grants-v1.json`，SDK 的刷新/登录写入等待 Rust 持久化确认；同一 profile 的保存、删除、登录、刷新和请求由互斥锁串行化。取消会终止本次运行时和回调监听。API 配置与授权是两个本地存储，保存失败会显示错误，重新保存可以修复。

自定义 API 继续使用 pi-ai 窄协议入口与 native fetch；Gemini 保留原生 functionCall/functionResponse 和 thoughtSignature。旧协议配置保持可用，编辑内置提供商后切换完整本地运行时。模型目录保留 api、端点、上下文、输出额度及推理能力；右下角选择同时切换实际提供商和协议。详见 [模型认证](model-authentication.md)。

账号凭据仍由 `deepseek_account.rs` 管理 PKCE、加密、过期与账号网页；API 密钥独立保存。只有官方账号请求的 401 才使该账号过期。无 DeepSeek 账号但有 API 提供商时进入工作区并选择可用的 API 模型。官方默认最大输出 256000，历史有效设置保留；第三方使用模型目录输出额度。截断轮不执行部分工具，不会因切换协议丢失已完成工具证据。

网页工具只在官方账号路线且开关打开时暴露，native 固定官方工具地址、90s 超时、4 MiB 响应限制及取消，读取正文最多 60000 字符。模块库检索仍优先，网页内容只作为数据。账号赠金通知沿用 Harness 的会话内控制器，read/ack 绑定随机授权作用域，注销与账号切换清空旧卡片与重试。

## 执行与完成

```text
用户需求
  → 识别独立问候或开发任务
  → 组装上下文、必要的知识证据和原生工具定义
  → DeepSeek 流式推理 / 正文 / 工具参数
  → 整批参数完整性校验
  → 执行工具并保留结果
  → 继续下一轮；有源码修改则要求最新版本构建
  → 完成交付，或报告取消 / 具体失败 / 未完成原因
```

- 独立问候、致谢和能力介绍使用轻量提示词，不带旧工程历史和工具；正常只需一轮。混合开发需求仍走开发流程。
- 开发任务默认自主分析接口和实现方案，自动读写；知识库返回多个入口不会自动转换成用户选择题。只有业务信息缺失或用户明确要求时才使用结构化提问。
- 桌面入口没有固定总轮数或整轮计时上限。调用方可显式传入 `maxSteps`，用于集成和测试。
- 主模型单次请求仍有 180 秒超时；网络失败最多重试两次。连续相同失败且无源码变化、连续空响应或相同本地检查失败且无新工具证据时报告明确原因。成功读取同一文件不会触发重复操作终止；每次修改后构建重试计数重新计算。
- 源码保存、精确替换、恢复快照或工程生成都会影响修改状态。最新修改之后必须再次验证，旧构建不能证明新源码可用。
- `build_ecode_project` 已包含回编和编译；成功后无需重复 `compile_efile`。转换器即使输出 `SUCC`，有解析错误日志也按失败处理。
- 停止信号贯穿模型请求、已接入的工具和 Rust 任务注册；忽略迟到流内容。恢复上次中断会话时保留结果、清除失效的运行标记。

### 输出截断恢复

`finish_reason=length` 生成独立的 `LLMOutputLimitError`。适配器先校验整轮，再发布工具调用，因此截断批次内即使有一个看似完整的调用也不会执行。

执行器丢弃本轮残缺正文、推理和工具参数，在同一模型轮内最多恢复两次。恢复提示逐次要求只完成一个文件片段、子程序或最小补丁，其余工作交给后续工具轮。既有成功工具和结果保持原样，残缺 JSON 不会拼接到下一次请求，恢复指令只作用于当前重试。

输出恢复计数与网络重试计数独立，也不占用新的正常工具轮。仍被截断时明确以未完成错误结束，不把残缺源码或失败候选答案显示为交付。

## 易语言工程与知识库

已有 `.e` 工程优先使用 `start_project_closed_loop` 做导出、项目地图、原始基线、上下文与快照；允许编辑后读取推荐源码，修改 `.e.txt`，再用 `finish_project_closed_loop` 验证。基线、依赖或环境不满足时不能跳过检查声称完成。

新建窗口使用 `generate_gui_project`：`.form.json` 保存几何布局，`.form.e.txt` 保存窗口程序集和事件，再回编 `.e`、编译 `.exe`。目前支持按钮、编辑框、标签、选择框和单选框；不等同于任意控件的可视化设计器。

大文件可按范围读取并返回哈希。精确替换在后端对完整文件执行，要求唯一匹配，并可校验预期哈希；编码和换行尽量保持。`.e/.ec` 必须用解析工具，不按普通文本读取。

用户模块库接收 `.ec`，文件副本保存在应用本地目录；设置只存小体积元数据，API 和向量索引分开保存在 IndexedDB。模块库页懒加载、延迟搜索，每页 20 行。嵌入模型为随项目提供的本地 `bge-small-zh-v1.5`，ONNX 运行时通过 `scripts/prepare-ort.mjs` 从锁定的 npm 依赖准备，禁止回退下载远程模型。

## 展示与滚动

- 正文直接显示流式 Markdown；推理与正文分开，工具过程使用可展开的单行记录。调用数据只有展开时才挂载，完成后收起过程。
- 右侧工作区保留开始、文件、代码、多个终端与浏览器页签；收起时保持状态，关闭页签或切换会话释放对应资源。代码支持独立滚动、复制、保存、系统打开、换行和宽度调整。新增工具结果不抢当前文件。
- 长文件预览分页加载并检查哈希，文件变化停止拼接，读取失败保留现有内容供重试。二进制工程和可执行文件使用独立打开入口。
- `useLayoutEffect` 和直接 `ResizeObserver` 回调在显示前校正底部位置，区分程序滚动、内容收缩和用户上翻。向上阅读暂停跟随，“回到最新”恢复；关闭浏览器滚动锚定和平滑滚动。
- 代码高亮缓存已完成行及语法状态，只重算增长尾部；高亮加载和追加过程中保持同一 `pre/code` 及已有行节点，避免字体几何变化和整块替换引起抖动。

## 与参考项目的关系

DeepSeek Harness 为本地只读对照项目，没有修改其源码或以它作为运行时依赖。对照包括 `ui-conversation/InputBar`、模型选择、`ui-chat/TurnProcessNodeView`、`ui-tool/ToolRow`、`ui-sidebar-documentpreview/TextPreview`、`core/agent-loop` 和 `llm-deepseek`。界面使用其 `ui-theme/design-platform.css` 配色，保留本项目的名称、图标、React/Tauri 架构与易语言工具。

Harness 的 DeepSeek 默认输出额度为 256000，使用 Messages 协议；本项目使用 Chat Completions。默认预算、原生工具循环和滚动机制已参考实现，但并未完整移植其 Markdown 分块缓存、所有工具独立滚动和折叠位置保持逻辑。Harness 也会区分 `max-tokens` 与正常完成；本项目额外增加了上述有限截断恢复。

[AutoLinker](https://github.com/aiqinxuancai/AutoLinker) 用于参考分页读取和哈希校验修改；原生窗口生成由本项目实现。

## 已知边界

工具上下文还没有统一的 Token 总预算；过多源码或工具结果仍可能超出模型上下文。本地结构检查不能代替实际编译和业务验证，文件修改后的构建证据必须覆盖最新源码。桌面 Rust 和前端检索路径尚未做统一端到端验收，复杂工程依赖与停止后编译器派生进程树也需继续验证。

当前自动化主要使用模拟模型传输；构建和回归通过不代表真实 DeepSeek 的连接、延迟、工具选型或生成质量已经验证。验证方法见[开发与验证](development.md)。

## 模块导入与工作区原生能力（0.1.3）

模块导入先登记“复制中”，由 Rust 复制 `.ec` 并返回大小，避免用文本读取器读取二进制来统计大小。原生解析结束后，ES Module Worker 整理命令、程序集及其他声明，并分批建立本地语义向量。Worker 复用嵌入模型、串行安排向量任务，解析请求不排在整个向量队列之后。主线程只接收阶段和数量更新，词法索引先于向量索引可用。详情按需读取，原始文本分页，不把整份模块挂载到 DOM。

用户库先于精易库进行自动预查；模块详情包含内部声明，但搜索仅返回公开接口。结果包含依赖路径，运行器记录本轮检索/解析确认的 `.ec`，传给生成与编译工具。同一批次后续调用也能获取新发现的依赖。

`workspace.rs` 提供目录分页、ConPTY PowerShell 终端和 Tauri 子 WebView。目录限制在所选工作区内；终端在关闭页签时结束进程。浏览器仅接受 http(s) 网页，隐藏页签或打开设置时隐藏原生表面，并跟随布局位置。默认插件能力只赋予 `main` WebView；应用自定义命令另在调用入口拒绝子网页，避免仅依赖插件 ACL。主视图显式获得 `opener:allow-open-path`，修复本地打开的 ACL 错误。

`system_tray.rs` 创建 Windows 托盘图标与打开/退出菜单；主窗口的 `CloseRequested` 由 Rust 拦截并隐藏，保留 WebView 和当前任务。托盘左键、打开菜单和单实例回调复用恢复逻辑；明确选择退出时才调用应用退出。

易语言环境页仅在点击“扫描环境”后调用异步命令，文件遍历由 `spawn_blocking` 执行，不占桌面事件线程；全局信号量拒绝重叠扫描。前端用请求序号丢弃目录更改或弹窗关闭后的旧结果。递归文件统计跳过符号链接及 Windows junction，每轮限制 100,000 条目、64 层及 10 秒检查预算；单次系统文件调用自身不承诺超时。遇到跳过项或达到预算时返回 `counts_complete: false` 与警告，数量仅代表已扫描部分。

## 安装与首次启动

`src-tauri/installer/` 直接适配 Harness 的原生展示源码，`scripts/prepare-installer.ps1` 编译 x86 DWM/GDI+ helper 并生成 EAiCoding 品牌位图。固定 600×600，按钮/路径/完成页布局和动画保留原实现；进度源改接 Tauri 的原生文件安装进度，成功完成才显示 100%。安装、WebView2 检查、产品注册及卸载继续由 Tauri CLI 2.10.1 模板处理，安装路径使用 Harness 的本地路径/重解析点/目录归属检查。

授权网络阶段可即时取消；凭据提交在互斥锁中完成，提交事务不被外部 future 的取消中断。取消或退出后，迟到的交换结果不能写入凭据。退出登录卸载工作区时中止正在运行的 Agent，迟到的模型输出不再覆盖已停止的记录。所有授权返回值仅投影非敏感信息到前端。登录和安装适配来源见根目录第三方声明。

## 账号菜单与个人中心（0.1.4）

侧栏显示头像和账号名，向上菜单提供设置及退出登录；设置和 Ctrl+, 默认进入个人中心，模型页管理提供商与目录，推理强度在输入区选择。菜单通过 portal 定位，支持方向键和 Escape，关闭恢复账号按钮焦点。菜单、设置和退出确认弹窗出现时隐藏原生浏览器表面。

Rust 在锁外并行请求开放平台 `/auth-api/v0/users/current` 与 `/api/v0/users/get_user_summary`；只在固定官方主机注入敏感授权头，拒绝重定向，限制超时和响应体积。前端只收到姓名、联系方式和两类钱包，不收到令牌或原始用户对象。401/40003 清除匹配的授权并通知登录状态更新；返回前再次核对当前授权，前端用请求版本隔离退出和换账号后的迟到结果。

资料和余额可分别降级，失败保留官方查看入口，切换设置分类不重复请求。余额使用 big.js 保留十进制精度，按 Harness 的两位小数和微额规则显示。退出确认取消不停止任务，确认退出后通过现有登录门中止运行并忽略迟到输出。

## 安装解压与进度（0.1.4）

安装器仍使用 Tauri 的版本、注册表、快捷方式和卸载清单。NSIS 编译时用 `prepare-installer-payload.mjs` 将 Tauri 提供的实际主程序、工具及许可证打为独立非 solid LZMA2 包，外层 NSIS 不再次压缩该包。固定 `7zip-bin` 5.2.0 的 Windows x64 工具随安装器提供，不在用户机器下载或寻找外部解压器。

从 Harness 适配的 `extract.h` 在 NSIS 工作线程启动无窗口的独立 7-Zip 进程，读取管道内的百分比并通过窗口属性发布；限制继承句柄，子进程置于关闭即结束的 Job。只有退出码零允许继续注册，解压/启动失败停止安装。绘制线程只读属性，不同步查询后台进度控件；复用 DPI 画布，品牌图只绘制一次，每帧仅更新进度与状态区域。准备 WebView2 时显示对应状态；阶段内百分比是进度映射而非剩余时间，只有安装成功才能绘制 100%。

本次未移植 Harness 的整目录暂存/切换升级方案，仍沿用 Tauri 的覆盖安装与卸载流程。独立压缩包准备期间没有文件级进度，显示准备状态和活动动画；磁盘或运行环境下载变慢仍会增加耗时。

## Windows 标题栏菜单

应用与编辑入口采用 Harness 的 caption-menu 结构，通过受主 WebView 限制的 `show_caption_menu` 命令打开 Tauri 原生菜单。应用操作事件只发送给主视图；编辑通过本机快捷键进入输入控件的真实撤销/剪贴板栈，发送前核对前台窗口。关于、更新结果与退出确认使用标题栏下方的应用弹窗；原生网页在弹窗显示期间隐藏，防止遮挡。更新检查只查询本产品 GitHub 发布记录。

DeepSeek Messages 将原生思考签名与应用当前文本/工具调用分开重放，过滤空消息并在发送前验证调用和结果。服务端错误原因以有限长度的脱敏文本传回对话，不再仅显示 HTTP 状态码。

思考文本作为持久内容保存，原生签名仅在模型与推理匹配时复用；原生重放降级不删除现有推理。历史正文压缩保留思考状态，旧会话可从最终回答步骤恢复被界面清空的推理。应用自动预查属于运行器提供的工具证据，使用用户上下文观察而非伪造模型 assistant/tool_use；模型工具续调则完整保留该轮推理与调用/结果配对。

## 会话独立运行与队列

ChatView 按 sessionId 注册每个运行句柄与状态；配置读取前同步锁定对应会话，每次执行拥有自己的文本、推理缓存和动画帧。界面只读取当前会话的运行状态，后台回调只写自己的消息，不改变前台任务的状态或滚动位置。结束时仅注销自身，所有运行均结束后才关闭持久化节流；每轮最终状态主动刷盘。删除会话或卸载时取消对应运行与动画帧，账号退出取消官方账号运行。

队列逐会话调度，每轮成功才自动继续；停止、失败或配置错误暂停该会话自动续队。QueueDock 的单条预览、多条折叠、原位编辑和图标顺序对照 Harness；指定发送优先交给该会话的 steer，未运行时启动指定消息，接受成功后才移除。草稿和附件按会话保存在内存中，异步接受只清除对应的原始草稿，防止覆盖后续编辑。

思考折叠采用固定行高与 contain:size layout，摘要允许 flex 收缩并以省略号显示；消息 viewport 的内部内容层使用固定列宽，替代 Radix 默认 table 的固有宽度行为。展开内容按列换行，代码仍在自己的容器滚动。
